# RAG Training Corpus

Drop organization-specific Collibra workflow material here:

- Exported workflow packages: `.zip`, `.bpmn`, `.app`, `.form`
- Standards and runbooks: `.docx`, `.pdf`
- Asset inventories and relation maps: `.xlsx`
- XML schemas and integration specs: `.xml`
- Java API documentation exports or scraped HTML

The ingestion pipeline extracts text, BPMN structure, form schemas, UUID-like values, Excel header relationships, and source-target relation candidates.
