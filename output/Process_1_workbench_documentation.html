1. Purpose

This workflow automates the approval and update process for Collibra assets related to governance policies. It streamlines request submission, steward review, asset updates, and notifications, ensuring compliance and efficiency in governance workflows.

---

2. BPMN Flow Overview

**Main Steps:**

  • **Start:** Requester submits a request via form.
  • **Review:** Data Steward reviews the request.
  • **Decision:** Steward approves or rejects.
  • **If Approved:**

- Asset is updated via API call.

- Requester is notified of completion.

  • **If Rejected:**

- Workflow ends with rejection notification.

**Flow Summary:**

  • Sequential request submission → review → decision → action → notification → end.
  • Parallel paths for approval and rejection.
