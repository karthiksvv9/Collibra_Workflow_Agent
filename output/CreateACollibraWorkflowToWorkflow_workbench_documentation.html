Purpose

Automate the creation of relations between assets in Collibra by validating requests, obtaining steward approval, and applying metadata updates.

---

Workflow Overview

  • **Start**: Initiated by requester via form.
  • **Validation**: Checks request integrity.
  • **Review**: Steward reviews and approves/rejects.
  • **Decision Gateway**: Routes based on approval.
  • **Metadata Application**: Applies relation creation.
  • **End States**: Successful completion or rejection.

Route Logic

| Transition | Condition | Description |

|--------------|--------------|--------------|

| Start → Validate | N/A | Initiates validation process. |

| Validate → Review | Validation passes | Sends request for steward review. |

| Review → Gateway | Review complete | Approves or rejects request. |

| Gateway → Apply Metadata | `${approvalDecision == 'approve'}` | Proceed if approved. |

| Gateway → Rejected End | `${approvalDecision != 'approve'}` | Workflow ends if rejected. |

| Apply Metadata → Success End | N/A | Finalizes relation creation. |
